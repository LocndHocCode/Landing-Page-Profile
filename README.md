# Landing Page Profile Cá Nhân

Đây là dự án xây dựng một trang Landing Page cá nhân (Portfolio) đơn giản và hiện đại, giới thiệu thông tin bản thân, kinh nghiệm làm việc (đang cập nhật), các dự án nổi bật và thông tin liên hệ.

Trang web được thiết kế để hoàn toàn responsive, hiển thị tốt trên nhiều kích thước màn hình khác nhau, từ điện thoại di động đến máy tính để bàn.

## ✨ Tính năng chính

*   **Giới thiệu bản thân:** Khu vực Hero section nổi bật với ảnh đại diện và mô tả ngắn gọn.
*   **Kỹ năng/Công nghệ:** Liệt kê các công nghệ đã làm việc (sử dụng icon Font Awesome).
*   **Dự án nổi bật:** Hiển thị các dự án cá nhân hoặc công việc tiêu biểu dưới dạng thẻ (card) trực quan với hình ảnh thumbnail.
*   **Kinh nghiệm làm việc:** Khu vực hiển thị quá trình làm việc (hiện đang "Đang cập nhật...").
*   **Thông tin liên hệ:** Bao gồm địa chỉ email (mailto link) và các liên kết mạng xã hội (GitHub, Facebook, Telegram) mở trong tab mới.
*   **Responsive Design:** Giao diện tự động điều chỉnh phù hợp với mọi kích thước màn hình.
*   **Giao diện sáng:** Sử dụng theme màu sáng, dễ nhìn.

## 🚀 Công nghệ sử dụng

*   **HTML5:** Cấu trúc nội dung trang web.
*   **CSS3:** Định dạng giao diện, bố cục và hiệu ứng.
*   **JavaScript (Cơ bản):** File `script.js` được liên kết (hiện chỉ có `console.log`), sẵn sàng cho việc thêm các tương tác động.
*   **Font Awesome (CDN):** Sử dụng thư viện icon phổ biến để hiển thị các biểu tượng một cách nhất quán và dễ dàng.

## 💻 Cách xem trang web

1.  Clone repository này về máy của bạn (nếu bạn đã đưa lên GitHub):
    ```bash
    git clone <URL-repository-cua-ban>
    cd <ten-thu-muc-repository>
    ```
2.  Mở file `index.html` trực tiếp bằng trình duyệt web (nhấp đúp vào file hoặc kéo thả vào cửa sổ trình duyệt).

Hoặc nếu bạn deploy trang web lên một dịch vụ hosting (như GitHub Pages, Netlify, Vercel), bạn có thể truy cập qua đường dẫn công khai.
